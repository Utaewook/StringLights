# Design Assets

This directory contains the screenshots, the visual references, and the mockups that [`../direction.md`](../direction.md) uses.

- Keep the files small.
- Give each file a name that tells what it shows. Examples: `legacy-v1-inspector.png`, `reference-editorial-density.png`.
- Do not commit a large binary file. Put a link to it instead.
- A file is "large" if it is **more than 5 MB**. You can commit a file of 5 MB or less.
- The demo GIF has the same limit. See [`../demo-recording.md`](../demo-recording.md).
