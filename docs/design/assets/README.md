# Design Assets

Screenshots, visual references, and mockups referenced by
[`../direction.md`](../direction.md).

Keep files small and name them by what they show, e.g.
`legacy-v1-inspector.png`, `reference-editorial-density.png`.

Large binaries do not belong here — link them instead. "Large" means **over 5 MB**;
a file at or under that may be committed. The demo GIF is held to the same limit
(see [`../demo-recording.md`](../demo-recording.md)).
